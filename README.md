# MangaOverlay — แอปแปลมังงะบนหน้าจอ (Android)

โปรเจกต์นี้ถูกจัดโครงสร้างแยกไฟล์มาตรฐานเหมือนแอปกล้อง **FujiCam** เพื่อให้แก้ไขโค้ดได้ง่ายและอัปโหลดขึ้น **GitHub** เพื่อสั่ง Build เป็นไฟล์ `MangaOverlay.apk` ได้อัตโนมัติ

## ดาวน์โหลด APK จาก GitHub (ไม่ต้องมีคอมพิวเตอร์)
ทุกครั้งที่อัปโหลดโค้ดขึ้น GitHub ระบบจะ build แอปให้อัตโนมัติ
1. เข้าแท็บ **Actions** ในหน้า repo แล้วเลือกรายการล่าสุดที่มีเครื่องหมายถูกสีเขียว
2. เลื่อนลงไปที่ **Artifacts** แล้วกดดาวน์โหลด **MangaOverlay-apk** (จะได้ไฟล์ zip ที่มี `MangaOverlay.apk` อยู่ข้างใน)
3. แตกไฟล์ zip แล้วเปิด `MangaOverlay.apk` บนมือถือเพื่อติดตั้ง (อาจต้องอนุญาต "ติดตั้งแอปที่ไม่รู้จัก")

ถ้าอยากได้ลิงก์ดาวน์โหลดถาวร ให้ไปที่ **Releases › Draft a new release** ตั้งชื่อแท็กขึ้นต้นด้วย `v` เช่น `v1.1` แล้วกด Publish ไฟล์ APK จะถูกแนบให้อัตโนมัติ

## ใหม่ในเวอร์ชัน 1.1 (สิ่งที่ปรับปรุงแก้ไขแล้ว)
- **แยกโครงสร้างไฟล์โปรเจกต์มาตรฐาน:** แกะโค้ดออกจาก Base64 ใน `build.yml` มาเป็นโครงสร้างโปรเจกต์ Android มาตรฐานเหมือนแอปกล้อง (`app/src/main/...`, `build.gradle.kts`, `.github/workflows/build.yml`)
- **แก้ปัญหากล่องคำแปลทับกันเอง:** ลดขนาดขั้นต่ำของกล่องและเพิ่มระบบตรวจจับการชนกันของกรอบคำพูด (`placedRects`) ไม่ให้กล่องที่ขยายขนาดไปบังบอลลูนข้างเคียง
- **โหมดสำรอง (ML Kit Offline) ฉลาดขึ้น:**
  - ตรวจจับตัวอักษร ญี่ปุ่น / เกาหลี / จีน / อังกฤษ อัตโนมัติแม้ตั้งค่าภาษาเป็น "ตรวจภาษาอัตโนมัติ"
  - เรียงลำดับบรรทัดมังงะญี่ปุ่นและจีนแนวตั้งจาก **ขวาไปซ้าย** อัตโนมัติ ไม่สลับประโยคหน้า-หลัง
- **แก้ปัญหาโหมดแปลอัตโนมัติ (AUTO) แปลซ้ำวนลูป:** ตัดขอบบน 8% (นาฬิกา/แจ้งเตือน) และขอบล่าง 12% (แบนเนอร์โฆษณา/แถบนำทาง) ออกจากการคำนวณการเลื่อนหน้าจอ
- **เปลี่ยนโมเดลหลักเป็น `gemini-2.5-flash`:** แม่นยำในการหาพิกัดกรอบคำพูด (`box`) และเสถียรกว่าเดิม พร้อมสลับไป `gemini-flash-latest` และ `gemini-flash-lite-latest` อัตโนมัติเมื่อโควตาเต็ม

## โครงสร้างโค้ด
- `MainActivity.kt` — หน้าตั้งค่าหลัก, ทดสอบ API Key, เลือกภาษา/โทนเสียง, คำศัพท์ชื่อตัวละคร (Glossary)
- `OverlayService.kt` — บริการปุ่มลอย, จับภาพหน้าจอด้วย MediaProjection, วาดกล่องคำแปลทับหน้าจอ
- `Translator.kt` — เอนจินแปลภาษาควบคู่ Gemini Vision API และ Google ML Kit On-Device (Offline Fallback)
- `Prefs.kt` — จัดเก็บการตั้งค่าและบันทึกข้อผิดพลาด
